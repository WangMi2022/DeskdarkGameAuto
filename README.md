# 复古打宝挂机助手（Windows EXE）

这是一个独立桌面程序，不需要 Tampermonkey。启动后会在窗口中打开 `https://game.placegame.cn/`，并加载自动强化、金币材料、世界 BOSS、自动爬塔和自动领奖面板。

运行 `PlacegameAutoHelper.exe` 时请保留它所在目录的全部文件。便携版使用自己的 Electron 用户目录保存游戏登录会话，程序不会保存账号密码。

使用流程：

1. 在程序窗口登录游戏并进入角色，点击面板中的刷新。
2. 在装备列表勾选目标装备。只要手动勾选，范围会自动切换为“仅勾选装备”；点击开始后本轮装备和参数会锁定。
3. 设置强化等级、金币保留额和失败策略，然后点击“开始自动强化”。
4. 在“金币材料”中可单独购买，也可“一键购买三种”：强化石 1000 个、洗练石 1000 个、高级强化石 999 个。只购买系统行商的金币订单，显示份数与总价，按整份分批完成，禁止超购。截图所示分别为 50 份（20 个/份）、125 份（8 个/份）、333 份（3 个/份）。每个请求最多 99 份；程序按实际订单份量计算，无法凑齐时不购买。
5. 在世界 BOSS 页选择开放场次后点击“一键挑战世界BOSS”。关闭循环时每个选中场次参与一次，开启循环时直到次数用完或达到本次上限。
6. 在“自动爬塔”设置目标层数和间隔，点击开始。默认使用服务器列出的前三个技能、不附加增益或词缀；从当前可挑战层开始，胜利后继续，失败、未解锁、封顶、达到目标或结果不明确时停止。不会自动扫荡或重复重试失败楼层。
7. 在“自动领奖”中可单独领取公会奖励、活动奖励，或一键领取全部。程序只提交服务器明确标记为可领取的免费奖励：公会每日分红、捐献进度奖励、活动签到、活跃箱、任务、成就、图鉴和推币场已解锁奖励；不会开始小游戏、购买彩票、兑换、捐献或执行付费项目。

强化和购买操作都会先检查服务器返回的条件；遇到余额不足、材料不足、场次关闭、限流或登录失效时会停止并写入日志。购买前重新核对金币、订单份量和价格；网络异常时不自动重发购买或爬塔请求，先在游戏中核对结果再操作。停止按钮和关闭面板会阻止后续请求，已经提交到服务器的请求无法撤回。可用“助手 → 重新打开助手面板”恢复面板。

0.1.5 增加公会与活动免费奖励领取，并适配游戏前端 0.2.62；0.1.3 修正了 0.1.2 将金币行商误接到元宝兑换接口的问题，购买数量按“每份数量 × 份数”计算。

## 从源码构建

需要 Node.js 22.12 或更高版本，在 Windows PowerShell 中运行：

```powershell
npm install
npm run test:helper
npm run portable
```

便携版输出在 `dist-portable-final-v<版本>\PlacegameAutoHelper-win32-x64`，运行其中的 `PlacegameAutoHelper.exe`。

测试使用 Electron 加载真实助手面板，但所有 HTTP 请求均为离线模拟，不会连接游戏服务器，也不会消耗账号资源。
